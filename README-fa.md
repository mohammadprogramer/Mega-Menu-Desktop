# Ramka Elementor Product Mega Menu — 1.0.21

این نسخه بر پایه مسیر ثبت و رندر پایدار نسخه 1.0.5 ساخته شده و هیچ تبدیل Shortcode/HTML روی داده Theme Builder انجام نمی‌دهد. هدف اصلی یکسان بودن خروجی ویجت در Elementor و هدر منتشرشده است.

- رنگ اصلی: `#47578A`
- لوگوی اختصاصی دسته: محصولات ← دسته‌بندی‌ها ← ویرایش دسته ← Mega menu logo / image
- اولویت تصویر: تصویر اختصاصی مگا منو ← Thumbnail ووکامرس ← SVG داخلی
- تعداد محصولات در منو نمایش داده نمی‌شود.
- Overlay دسکتاپ و دستکاری `body/html` انجام نمی‌شود.
- Widget به روش استاندارد `elementor/widgets/register` ثبت می‌شود.

## تغییرات نسخه 1.0.21

- حفظ کامل مسیر سازگاری Frontend هدر نسخه 1.0.20.
- اضافه شدن انتخاب‌گر تصویری آیکون برای هر دسته محصول در «محصولات ← دسته‌بندی‌ها».
- امکان انتخاب لوگو/تصویر اختصاصی برای هر دسته با اولویت بالاتر از آیکون داخلی.
- اضافه شدن حالت مگا منوی عریض دسکتاپ با عرض پیش‌فرض 1280px قابل تنظیم در Elementor.
- بازطراحی preset فروشگاهی با ستون دسته اصلی فشرده‌تر، فضای محتوای بزرگ‌تر، چهار ستون پیش‌فرض و ساختار متنی سبک‌تر.
- حفظ رنگ اصلی رابط روی #47578A و عدم نمایش تعداد محصولات.
